### XAMPP Setup
1. Extract to `C:\xampp\htdocs\SmartCycle_AI`
2. Start Apache and MySQL.
3. Import `database/smartcycle.sql` in phpMyAdmin.
4. Open `http://localhost/SmartCycle_AI/login.php`.

### Modules
Dashboard, Bicycle Catalog, Customers, Sales, Leads, Smart Inventory, AI Recommendations, AI Forecast, Customer Intelligence, AI Sales Assistant, Service Center, Test Rides, Smart Offers, Notifications, Calendar, Team, Reports, Dark Mode and responsive UI.

AI modules are implemented as an academic/demo intelligence layer. A real ML model or AI API can be connected later through secure server-side integration.
